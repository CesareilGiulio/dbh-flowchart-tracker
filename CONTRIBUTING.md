# Contributing / Contribuire

*[Italiano più sotto](#italiano)*

## Reporting a mistake

The most useful contributions are corrections to the flowcharts. Open an issue with:

- the chapter and, if it has more than one, the flowchart (for example *Battle for Detroit – Kara Captured*);
- the node, by its English name;
- what is wrong (missing node, wrong link, typo, wrong translation);
- if you can, a screenshot of the in-game flowchart showing the right version.

Screenshots are especially welcome for the nodes with a note starting with “Link to be verified”.

## Changing the data yourself

The flowcharts live in `data/manual/NN-chapter.json`. Chapters 22–32 are generated by the Python
scripts in `scripts/` (`gen_*.py`): for those chapters, edit the script and run it again, otherwise the
next run overwrites your change. Chapters 1–21 are edited directly in their JSON file.

After any change:

1. If you added or changed a note, add its English translation to `scripts/notes_en.py` and run
   `python scripts/translate_notes.py`.
2. Bump the chapter's `rev` (for example from `manual-1` to `manual-2`), so that the app updates the
   chapter for existing users while keeping the nodes they have already unlocked.

Each node has `id`, `title` (Italian), `en` (English, as in the game), `type` (`checkpoint`, `choice`,
`objective` or `ending`), `parents` (ids of the nodes it comes from) and optional `note` / `note_en`.
Ids must be unique within a chapter, and every parent must exist. Nodes with the same name in different
places of a flowchart are separate nodes, told apart by a note.

## Italiano

### Segnalare un errore

I contributi più utili sono le correzioni ai diagrammi. Apri una issue indicando:

- il capitolo e, se ne ha più di uno, il diagramma (per esempio *Battle for Detroit – Kara Captured*);
- il nodo, con il nome inglese;
- cosa non va (nodo mancante, collegamento sbagliato, refuso, traduzione);
- se puoi, uno screenshot del diagramma nel gioco con la versione giusta.

Gli screenshot sono preziosi soprattutto per i nodi con la nota «Collegamento da verificare».

### Modificare i dati

I diagrammi stanno in `data/manual/NN-capitolo.json`. I capitoli 22–32 sono generati dagli script
Python in `scripts/` (`gen_*.py`): per questi va modificato lo script e rilanciato, altrimenti la
modifica viene sovrascritta alla generazione successiva. I capitoli 1–21 si modificano direttamente
nel loro JSON.

Dopo ogni modifica:

1. Se hai aggiunto o cambiato una nota, aggiungi la traduzione inglese in `scripts/notes_en.py` e
   lancia `python scripts/translate_notes.py`.
2. Aumenta il `rev` del capitolo (per esempio da `manual-1` a `manual-2`): così l'app aggiorna il
   capitolo per chi la usa già, mantenendo i nodi sbloccati.

Ogni nodo ha `id`, `title` (italiano), `en` (inglese, come nel gioco), `type` (`checkpoint`, `choice`,
`objective` o `ending`), `parents` (gli id dei nodi da cui arriva) e, facoltative, `note` / `note_en`.
Gli id devono essere unici nel capitolo e ogni genitore deve esistere. I nodi con lo stesso nome in punti
diversi del diagramma restano nodi separati, distinti da una nota.
